# First authored scene

After the stock cube task works, create a minimal scene with a fixed SO-101 follower, table, nine-cell board, supply tray, one token, light, and overhead camera.

Use a small authored `.usda` composition that references a validated robot asset where practical. Keep geometry, robot articulation, keyboard/controller behavior, and task/reset logic conceptually separate: saving a visible scene does not establish that it can be controlled or recorded.

First scene checkpoint: stable physics, useful camera view, correct scale, and keyboard-controlled movement above the board. First manipulation checkpoint: one released token in the center cell.
